A tiny deterministic program that writes one original 175-character roast of wireless earbuds — the left one dying at 47% and abandoning the right to finish a true-crime episode alone — to `entry.txt`, after validating it against the bounty gate (UTF-8, 1–200 characters, single line, not only whitespace). Entered in the [One-Line Roast bounty](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610) on make.fun.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
